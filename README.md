# Esther Ehighelua — GRC Portfolio

Static multi-page professional portfolio for GitHub Pages.

## Publish with GitHub Pages
1. In the GitHub repository, open **Settings** → **Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. The site will publish at `https://esther-ehighelua.github.io/`.

## Before public launch
- Replace contact placeholders on `contact.html`.
- Verify all biography and professional details.
- Add only qualifications actually earned.
- Keep Nexora Digital Limited clearly labelled as a fictional simulation.
- Never upload confidential employer, client or third-party information.

Edit `index.html` for the homepage, `assets/css/style.css` for design and `assets/js/main.js` for the mobile navigation.
